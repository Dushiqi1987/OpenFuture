# 思考与工具时间线（逐步展开）验收记录

- 日期：2026-11-15
- 需求来源：「一行思考，然后显示前面一段，点开是该次时刻全部输出；一行是工具调用，点开是工具调用具体显示，最好能显示 tool result；skill 也独立显示；思考链用中文。」

## 目标

把原来「思考与工具」混在一起的链，改成 Codex 风格的逐步时间线：

1. 每一步一行：思考、工具调用、技能加载各占一行；
2. 折叠状态下只显示一行摘要（思考取首行、工具显示名字与参数提示、技能显示名字）；
3. 点击展开：思考显示完整文本，工具显示完整参数与工具结果，技能显示注入的指令；
4. 模型思考默认使用简体中文。

## 实现

### 协议（`src/shared/protocol.ts`）

```ts
| { type: 'skill'; name: string }
| { type: 'tool-start'; toolCallId: string; name: string; args?: string }
| { type: 'tool-end'; toolCallId: string; name: string; isError: boolean; result?: string; durationMs?: number }
```

### 宿主（`src/agent-host/index.ts`）

- `tool_execution_start` 附带 `args`（`JSON.stringify` 两空格缩进，裁剪到 2,000 字符）；
- `tool_execution_end` 附带 `result`（文本或 MCP content，裁剪到 4,000 字符）与 `durationMs`；
- `sendMessage` 在发送 `/skill:<name>` 时先发 `skill` 事件，渲染层据此在回合开头插入技能步骤；
- `before_agent_start` 的补充指令追加「思考过程请使用简体中文。」，回答语言不受限制。

### 渲染层（`src/renderer/src/App.tsx`、`styles.css`）

- 新增步骤模型：

  ```ts
  type TurnStep =
    | { kind: 'thinking'; id: string; text: string }
    | { kind: 'tool'; id: string; name: string; args: string; result?: string; isError?: boolean; durationMs?: number; done: boolean }
    | { kind: 'skill'; id: string; name: string }
    | { kind: 'note'; id: string; text: string }
  ```

- `applyEvent` 维护 `steps`：`thinking-delta` 续写当前思考步骤，`tool-start` 建工具步骤，`tool-end` 按 `toolCallId` 回填结果与耗时，`skill` 事件在下一回合开头生成技能步骤；
- 步骤行使用原生 `<details>` / `<summary>`：展开状态由浏览器维护，流式重渲染不会把它关掉；
- 工具行摘要从参数里提取 `path` / `command` / `query` / `pattern` / `url` / `name`，运行中显示 spinner，完成后显示耗时；
- 历史回放（没有 `steps` 的旧消息）会从 `thinking`、`toolNames` 与中间文本合成步骤，保证旧对话仍可阅读。

## 已知限制

- 历史会话只保存消息文本，不保存工具参数与结果；回放时工具行只有名字，展开后没有参数与结果。
- 思考文本来自模型返回的 `reasoning_content`（或等价字段），不同厂商的字段与详细程度不同；「使用中文」只是提示词约束，无法强制。
- 工具参数与结果分别截断到 2,000 / 4,000 字符，完整内容仍在会话文件与工具日志里。
- 每次 assistant 消息都可能带一段思考；多段工具调用会形成多个思考行，这是按消息呈现的结果。
