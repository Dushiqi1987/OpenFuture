# B0 项目记忆策略与隔离验收摘要

## 目标

每个项目拥有独立的记忆模式、资源、权限与版本；新建项目只提供四种用途：RAG、Wiki、Dreaming、关闭。旧 `both` 只保留给历史项目，并标记为“旧组合（高级）”。

## 实现

- `ProjectStore.setMemoryPreset` 持久化 `memoryPreset`；
- `projectsList` 对 active 项目回放策略，重启后仍一致；
- `projectsSetMemoryPreset` IPC 在 active 项目上立即应用到 `memory-host`；
- `memory-host.setMode` 首次使用时 `ensureWorkspace`，避免新项目无设置行；
- 创建页只渲染四个 `.preset-card`；
- MemoryPanel 模式切换回写项目策略，保留 `dreaming` 不被降级为 `both`。

## 验证

| 项目 | preset | `memoryState.mode` |
| --- | --- | --- |
| A | rag | rag |
| B | wiki | wiki |
| C | dreaming | both |
| D legacy | both | both |

- B 项目的笔记列表只有 B 的笔记；B 搜索 A 的笔记无命中，A 搜索可命中；
- 重启后 active 仍为 B、preset/mode 不变、只看到 B 笔记；
- 强制 `memorySetMode('off')` 后再次 `listProjects` 会回放项目策略；
- 干净 OF-03 通过：`ok:true`。
