# 模型提问与确认（ask_user）（2026-11-14）

## 背景

用户（m04803）要求：模型在开工前可以像其他 agent 产品一样向用户提问、请求权限或澄清需求，例如「写一个游戏」时先问「想做哪种？」，给出几个选项，也允许自定义回答。

## 业界做法

| 项目 | 工具/机制 | 交互形态 |
| --- | --- | --- |
| Cline（71.6k★） | `ask_followup_question`：question + 2–5 个 suggestion | 聊天流里出现选项按钮 + 输入框 |
| Roo Code（24.2k★） | 同 `ask_followup_question` | 同上；另有模式切换确认 |
| Claude Code | `AskUserQuestion`：1–4 个问题、每题 2–4 个选项、始终带 Other | 终端选择器，方向键 + 自定义 |
| OpenHands | confirmation mode / security analyzer | 执行高风险工具前弹确认，允许/拒绝 |
| LangGraph | `interrupt()` + resume | 图执行暂停，等待外部输入后恢复 |
| Vercel AI SDK | 客户端工具 + `addToolResult` | 工具调用挂在 UI，用户操作后回填结果 |

共同点：**把「问用户」做成一个阻塞式工具**，工具执行暂停，用户在 UI 作答后把答案作为工具结果返回给模型；权限确认只是同一机制的一种选项组合（允许/拒绝）。

## 本项目实现

### 1. 工具 `ask_user`（`src/agent-host/ask-tools.ts`）

参数：

```json
{
  "question": "你想让我先做哪一种小游戏？",
  "options": [{ "label": "贪吃蛇", "description": "经典街机" }, ...],
  "allowCustom": true,
  "kind": "choice"
}
```

- 2–6 个互斥选项；`kind=confirm` 用于「允许/拒绝」型确认。
- 工具 `execute` 返回一个 Promise，直到用户作答/取消/停止才 resolve；答案文本形如 `用户选择了「打砖块」` 或 `用户自定义回答：…`，作为工具结果进入下一轮。
- 同一时刻只允许一个未回答提问；子 Agent、群聊角色拿不到该工具（它们不能阻塞用户）。
- 宿主在 `stop`、关闭会话时会 reject 所有挂起提问，避免回合卡死。

### 2. 事件与 IPC

- `AgentStreamEvent` 增 `{type:'prompt', prompt}` 与 `{type:'prompt-done', id, answer?, cancelled?}`。
- 渲染层作答：`openfuture:prompt:answer` → `AgentHost.answerPrompt` → host `promptAnswer` RPC。

### 3. 渲染层

- 对话区上方出现卡片：标题「模型想先确认一件事」/「需要你的确认」、问题正文、选项按钮（含说明）、自定义输入框 + 发送、右上角取消。
- 作答后卡片消失，工具结果回到模型；`prompt-done` 事件兜底清理。

### 4. mock 与验证

`tools/e2e-ask.mjs`（`MOCK_ASK=1`）：

```

```

## 已知限制

- 提问只存在于当前回合；应用重启/会话关闭后不会保留。
- 一次只能问一个问题；模型并行调用多个 `ask_user` 时，第二个会直接报错。
- 子 Agent 与群聊角色不能向用户提问。
- 暂无「记住本次选择」「多选」与超时自动取消。
