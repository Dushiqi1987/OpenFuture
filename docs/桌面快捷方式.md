# OpenFuture 桌面快捷方式

桌面上的 `OpenFuture.lnk` 每次双击都会先构建当前源码，再启动 Electron，因此不会打开旧的 `out/` 产物。

## 组成

- 快捷方式：`%USERPROFILE%\Desktop\OpenFuture.lnk`
  - 目标：`C:\Windows\System32\wscript.exe`
  - 参数：`"D:\OpenFuture\scripts\OpenFuture-latest.vbs"`
  - 起始位置：`D:\OpenFuture`
  - 图标：`D:\OpenFuture\build\icon.ico`
- 启动脚本：`scripts/OpenFuture-latest.vbs`
  - 使用 DSH 自带的 Node 24 执行 `electron-vite build`。
  - 构建成功后启动 `node_modules/electron/dist/electron.exe`。
  - 启动前清除 `PWD`、`ELECTRON_RUN_AS_NODE`、`OPENFUTURE_USER_DATA`，避免 Electron 被当作 Node 或误用隔离数据目录。
  - 构建失败时弹出错误框，不会静默打开旧版本。
- 命令行备用：`scripts/launch-openfuture.cmd`
- 重建快捷方式：`scripts/create-desktop-shortcut.ps1`

## 日志

- 启动日志：`.scratch/launcher-debug.log`
- 构建日志：`.scratch/launcher-build.log`

## 限制

- 依赖本机 DSH Node 24 路径；若 DSH 安装位置变化，需要重新生成快捷方式。
- 每次启动会先构建，通常增加几秒启动时间。
- 源码目录固定为 `D:\OpenFuture`。
