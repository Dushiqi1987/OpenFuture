# 上下文/速度/缓存命中验收记录

## 计算口径

- 提示 token：`input + cacheRead + cacheWrite`
- 上下文使用率：`提示 token / contextWindow`
- 速度：`output / (durationMs / 1000)`，单位 tok/s
- 前缀缓存命中率：`cacheRead / 提示 token`
- 无 usage 时三项显示 `—`

## 验证数据

Qwen3.7 Flash 单轮：

```text
input=517
output=37
cacheRead=1536
cacheWrite=0
durationMs=1056
```

推导结果：

```text
提示 token = 2053
上下文 = 2053 / 128000 = 1.6039%
速度 = 37 / 1.056 = 35.0379 tok/s
缓存命中 = 1536 / 2053 = 74.8173%
```

页面渲染：

```text
上下文 1.6% · 2.1K / 128K
速度 35.0 tok/s
缓存命中 74.8% · 1.5K 读
```

## 持久化

usage 来自 Pi `AssistantMessage`，随消息写入会话 JSONL；刷新页面并通过 `openConversation` 重新加载后，统计仍显示。

## 限制

- 速度是整轮平均，不含首 token 延迟。
- 缓存命中依赖服务商返回 `cached_tokens`；未返回时显示 0%，不是“未知”。
- 每次只显示最近一条带 usage 的 assistant 消息。
