# 2026-11-10 思考链、用量与发布

## 思考链

- 用户反馈每步工具调用会展开再折叠，要求 DSH 风格常显。
- 第一版：一个 assistant turn 一个头像，`<details>` 折叠链。
- 第二版：删除折叠，链常显；流式时自动滚到底部，历史 turn 不显示“生成中”。
- 验证：Qwen 流式 8 次采样，chain 始终 1 个，`details` 为 0。

## 用量

- 从 Pi `AssistantMessage.usage` 提取 input/output/cacheRead/cacheWrite/durationMs。
- 上下文 = 提示 token / contextWindow；速度 = output / duration；缓存 = cacheRead / 提示 token。
- 历史会话可从 JSONL 恢复 usage。
- 无 usage 显示 `—`。

## 发布

- 本地仓库此前无 remote；用户创建 `github.com/Dushiqi1987/OpenFuture` 后，SSH 推送成功。
- 发布时把功能拆成协议、agent-host、UI、样式、文档等多个提交，避免单个大提交。

## 教训

- Qwen thinking 模型的 `thinking_budget` 可能大于默认 maxTokens，必须提高最大输出。
- `memory_search` 只在项目记忆模式开启时暴露；模式关闭时模型说没有该工具是预期行为。
