# OpenFuture 网页版使用说明（2026-11）

桌面端的浏览器版本：同一个主进程、同一批项目与会话，打开浏览器就能继续聊。
界面按 DeepSeek 网页版的习惯做：左侧会话列表、中间对话、底部输入框。

## 一、怎么打开

前提：桌面端已在运行（它同时提供 8787 手机访问和 8790 网页版）。

1. 启动：双击 `start-all.ps1`，或手动运行 `npm run dev`。
2. 浏览器打开 <http://127.0.0.1:8790/>。
3. 左侧选项目、点一个会话就能看到历史；点「＋ 新对话」直接开聊。

启动日志里会出现：

```
[web] browser access http://127.0.0.1:8790/
```

## 二、现在能做什么

| 生成控制 | 停止生成、复制全文、重新生成 |

| 断线重连 | 顶部横幅可直接点击立即重试 |
| 刷新不丢回复 | 生成中刷新或关掉页面再打开，会自动回到该会话并继续接收字幕 |
| 生成中插话 | 回复途中继续输入，Enter 默认「插话」，模型本轮即可看到；下拉可切「排队下一轮」 |

| 主题 | 跟随系统 / 浅色 / 深色，侧栏 ◐ 循环切换，选择保存在浏览器 |
| 快捷键帮助 | 按 `?` 或顶栏 `?` 打开快捷键表 |
| 消息密度 | 设置抽屉里选「舒适/紧凑」，长对话更省屏幕 |

## 三、账号与扫码

网页版左下角的头像就是账户入口：

- **账号登录**：手机号 + 密码，登录后头像与昵称同步，显示余额。
- **扫码登录**：点「扫码登录」显示二维码和 6 位码，用手机 OpenFuture App 扫码确认即可（手机需登录同一账号）。
- **充值 / 管理**：跳转到账号平台的手机版页面（8090），下单后按配置走模拟支付或支付宝。
- 退出登录后回到本地工作区状态。

账号服务地址由桌面端的账户面板配置，默认 `http://127.0.0.1:8090`。

## 四、和桌面端的联动

- 网页打开某个会话时，桌面端会跟着切到同一个会话；在网页发消息，桌面端也能看到。
- 反过来，桌面端生成的内容会通过事件流同步到网页。
- 两边共用同一个 Agent 会话，不要同时在一个会话里发消息。

## 五、安装成桌面应用

页面带 Web App Manifest（`/manifest.webmanifest`）和图标（`/icon.svg`）：

- Chrome / Edge：地址栏右侧出现安装图标，或菜单「应用 → 安装此站点」。
- Android Chrome：菜单「添加到主屏幕」。
- iOS Safari：分享 →「添加到主屏幕」。

安装后以独立窗口打开、地址栏隐藏；仍然连接本机 8790，数据位置不变。

## 六、访问范围与安全

- 默认只监听 `127.0.0.1:8790`，只有本机能访问。
- 想局域网访问：设置环境变量 `OF_WEB_HOST=0.0.0.0` 再启动。
  注意目前网页版没有登录鉴权，局域网开放前应先加访问令牌（后续版本）。
- 关闭网页版：设置 `OF_WEB=0` 后重启桌面端。

## 七、端口与配置

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `OF_WEB_PORT` | 8790 | 网页版端口 |
| `OF_WEB_HOST` | 127.0.0.1 | 监听地址 |
| `OF_WEB` | 开启 | 设为 `0` 关闭网页版 |

## 十二、遇到问题先看这里

- 页面打不开：确认桌面端在运行、日志里有 `[web] browser access`、8790 没被占用（`OF_WEB_PORT` 可换端口）。
- 手机/别的电脑访问：默认只绑本机；需要局域网时设 `OF_WEB_HOST=0.0.0.0`，并注意网页版目前没有登录鉴权，只建议在可信网络里用。
- 会话列表空：检查 `openfuture.jwt` 无关，网页版读的是桌面端项目；先确认桌面端里能看到项目。
- 生成中刷新后卡住：等 5 秒会自动接回；仍不行点横幅重试。
