# 项目与记忆运行时架构

## 进程

- `src/main`：Electron 主进程、窗口、IPC、项目注册表、凭证。
- `src/agent-host`：utilityProcess，动态加载 Pi，执行流式对话和工具。
- `src/memory-host`：utilityProcess，独占 SQLite/FTS5、证据/笔记/Dreaming、QMD/Wiki 适配。
- `src/preload`：白名单 API。
- `src/renderer`：React 三栏 UI。

## 项目

`src/main/project-store.ts` 持久化 `config/projects.json`：

```ts
interface ProjectInfo {
  id: string
  name: string
  canonicalRoot: string
  memoryPreset: 'off' | 'rag' | 'wiki' | 'dreaming' | 'both'
  defaultModelRef: string | null
  archivedAt: string | null
  available: boolean
}
```

- 同一 `rootKey` 只允许一个项目；重复选择定位已有项目。
- 活动项目同步到 `settings.workspace`，Pi 会话仍按 cwd 过滤。
- 项目对话存在 `ConversationRecord`，首次发送才 bind `piSessionId`。

## 记忆

- `memoryPreset` 映射到 `MemoryMode`：`dreaming`/`both` → `both`。
- `memory-host` 按 workspace 规范路径 sha256 前 24 位隔离数据库行。
- B0 起 `workspace_wiki` 按工作区绑定外部 vault，避免跨项目可见。
- 回答引用通过 `MemoryCitation` 带到 UI。

## 用量

`AssistantMessage.usage` → `MessageUsage` → `ChatMessage.usage`。前端只读最近一条 assistant usage，不额外请求。
