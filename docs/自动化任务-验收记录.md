# 自动化任务验收记录

日期：2026-11-11  
分支：`main`  
状态：通过（开发构建，隔离 profile + 本地 mock）

## 目标

把 DSH 侧栏中的「自动化任务」从占位入口实现为可用的定时任务：

- 任务绑定项目，按一次/间隔/每日/每周运行；
- 支持在新建对话或创建任务的当前对话中执行，并保留可查看的对话记录；
- 支持暂停/恢复、立即运行、编辑、删除和运行记录；
- 应用关闭时不后台联网，启动后补跑最近一次错过的任务。

## 实现

### 协议

`src/shared/protocol.ts`：

- `AutomationScheduleKind = 'once' | 'interval' | 'daily' | 'weekly'`
- `AutomationTaskStatus = 'active' | 'paused' | 'ended'`
- `AutomationRunStatus = 'running' | 'succeeded' | 'failed'`
- `AutomationTask`、`AutomationRun`、`CreateAutomationInput`、`UpdateAutomationInput`
- API：`automationList/Create/Update/Delete/SetActive/RunNow/Runs`
- IPC：`openfuture:automation:*`

### 持久化

`src/main/automation-store.ts`：

- 文件：`<userData>/config/automation.json`；原子写入；损坏文件隔离为 `.corrupt-*`。
- 运行记录上限 500 条、每任务 40 条。
- 校验一次性时间、间隔 1–10080 分钟、`HH:mm`、星期 0–6。
- 一次性任务必须晚于当前时间；已结束的一次性任务不能直接重新启用，必须修改执行时间。
- 每周任务按本地时区计算下一次发生时间；同一天尚未到达执行时间时安排在当天。

### 调度

`src/main/automation-service.ts`：

- 每 15 秒 tick，启动后 2 秒先执行一次；`running` 集合防重。
- 每个任务运行使用独立 `AgentHost`；可通过 `targetConversationId` 复用指定对话，否则新建独立对话。
- 运行流程：读取当前模型凭证 → 若绑定当前对话且该对话已打开，直接向当前会话投递；否则在项目下创建/打开目标对话 → 打开 Pi 会话 → 发送任务指令 → 收集最终 assistant 文本 → 绑定/更新对话 → 写入运行记录。
- 15 分钟超时；失败/超时也落库。
- 工具桥固定任务项目 workspace，不依赖当前 UI 选择。
- 任务串行执行，避免多个任务抢占同一 AgentHost。

### 界面

`src/renderer/src/App.tsx` / `styles.css`：

- 打开「自动化任务」时加载任务和运行记录，每 5 秒刷新。
- 任务卡片显示项目、计划、下次运行、上次错误和状态。
- 操作：立即运行、暂停/启用、编辑、记录、删除。
- 新建/编辑表单：名称、项目、执行位置（当前对话/新建对话）、指令、重复方式（一次/间隔/每日/每周）、执行时间/间隔/星期。
- 已结束任务不再显示「启用」，避免把过去的一次性时间重新激活。
- 删除前使用确认框。

### 模型工具调用（automation_*）

`src/agent-host/automation-tools.ts` 新增四个工具，让模型可以在当前项目里直接管理定时任务：

- `automation_create`：创建任务；`target` 为 `current`（默认，当前对话）或 `new`（新对话）；`scheduleKind` 为 once/interval/daily/weekly，once 用 `delayMinutes` 或 `runAt`，daily/weekly 用 `timeOfDay`，weekly 另加 `weekday`。
- `automation_list`：列出当前项目任务与最近运行。
- `automation_set_active`：按 id 暂停/启用。
- `automation_cancel`：按 id 删除任务及运行记录。

工具请求经 `src/main/index.ts` 的 `handleAutomationToolForWorkspace` 处理，并通过 `ProjectStore.findByRoot(workspace)` 把操作严格限制在当前对话所属项目内；自动化任务自己的子 AgentHost 不注入这些工具，避免嵌套创建任务。

## 限制

- 暂不支持 cron/rrule 全语法，只支持一次、间隔、每日、每周。
- 每次运行默认新建对话；模型工具和界面表单都可选择复用当前对话。
- 运行记录可点击「打开对话」查看；对话列表不会在任务完成后自动刷新，切项目或重新打开面板时更新。
- 应用关闭时不会后台执行；重启后只补跑最近一次错过的任务。
- 任务串行运行；长任务会推迟后续任务。
- 首轮测试使用本地 mock；真实模型下的长任务、失败重试、超时与断网恢复尚未逐项验证。
- 自动化运行使用与手动对话相同的项目权限和工具边界；未额外提升权限。
