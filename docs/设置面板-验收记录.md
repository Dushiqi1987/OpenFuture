# 设置面板（Vibelution 式分组）验收记录 — 2026-11-13

## 目标

参考 `F:\VibelutionRuntimes`（运行时包）指向的 `F:\多agent项目\Vibelution` 工作台设置页，把
OpenFuture 原本单页的「模型与密钥」表单改造成**左侧分组导航 + 右侧内容**，并补齐真正可操作、
可持久化的外观与输入选项；不改变 agent-host 的核心架构。

Vibelution 一侧的设置来源：`web/src/routes/ConfigRoute.tsx`（六个大组）、
`web/src/routes/config/configCopy.ts`（组标题）、`config/editor_schema_data.py`（45 个叶子字段，
含 `ui.language`、`ui.refresh_rate`、`context_compression.keep_recent_steps`、`network.proxy_url` 等）。

## 本轮落地范围

| 分组 | 字段 | 存储 / 生效 |
| --- | --- | --- |
| 外观 | `theme`（system/dark/light）、`scale`（0.9/1/1.1/1.25）、`density`（comfortable/compact）、`showTimestamps` | `settings.json → ui`，渲染层立即应用 `data-theme/data-density/data-timestamps`；缩放在主进程 `did-finish-load` 时 `setZoomFactor` |
| 模型与密钥 | 原有 Base URL / 模型 ID / 显示名 / 上下文窗口 / 最大输出 / 推理开关 / API Key | `saveModel`，与之前一致 |
| 对话与输入 | `sendShortcut`（enter/ctrl+enter）、`thinkingLevel`（off/low/medium/high）、上下文压缩开关 | 快捷键立即影响 composer；思考等级经 `OPENFUTURE_THINKING_LEVEL` 传给 agent-host，变化时停止 host，新会话按新等级创建 |
| 工具与权限 | Computer Use、PowerShell、并行子 Agent + 并发数、群聊 Agent | `setToolAccess` → 重启 agent-host |
| 关于 | 版本、协议版本、数据目录、密钥状态、清除密钥 | 只读 / 清除密钥重启 host |

## 实现位置

- 协议：`src/shared/protocol.ts` — `UiTheme`、`MessageDensity`、`SendShortcut`、`ThinkingLevel`、
  `UiPreferences`、`SetUiPreferencesInput`，`PublicSettings.ui`，`OpenFutureApi.setUiPreferences`，
  `IpcChannels.uiPreferencesSet`。
- 存储：`src/main/settings-store.ts` — `DEFAULT_UI_PREFERENCES`、`normalizeUiPreferences()`、
  `SettingsFile.ui`、`getUiPreferences()` / `setUiPreferences()`、`hostEnvironment()` 里的
  `OPENFUTURE_THINKING_LEVEL`。
- IPC：`src/main/ipc.ts` — `parseUiPreferencesInput()`（逐项校验，中文错误文案）、
  `IpcChannels.uiPreferencesSet` 处理器（保存后 `setZoomFactor`；思考等级变化时 `host.restart()`）。
- 预加载：`src/preload/index.ts` — `setUiPreferences(input)`。
- 渲染层：`src/renderer/src/SettingsDialog.tsx`（分组表单 + 合并保存 + notice）、
  `src/renderer/src/App.tsx`（把 `ui` 应用为 `data-*`、主题按钮双向同步、`handleComposerKeyDown`
  按 `sendShortcut` 决定发送）、`src/renderer/src/styles.css`（`.settings-layout`、`.settings-nav`、
  密度/时间戳规则）。
- 宿主：`src/agent-host/index.ts` — `thinkingLevelFromEnv()`，`createAgentSession({ thinkingLevel })`。
- 窗口：`src/main/index.ts` — `did-finish-load` 时按保存的 `scale` 重新设置缩放。

## 验证

命令：`node tools/settings-smoke.mjs`（需要 `electron-vite build`；脚本复制真实配置到
`.scratch/settings-smoke-userdata`，用 CDP 驱动真实窗口）。

```
nav -> ["外观主题、界面缩放、消息密度","模型与密钥OpenAI 兼容端点与凭据","对话与输入发送快捷键、思考等级、上下文压缩","工具与权限PowerShell、Computer Use、多 Agent","关于版本、数据目录、密钥"]
appearance -> {"count":3,"values":["system","1","comfortable"]}
saved -> {"closed":true,"ui":{"theme":"system","scale":1,"density":"compact","showTimestamps":true,"sendShortcut":"enter","thinkingLevel":"medium"}}
datasets -> {"density":"compact","timestamps":"on","theme":"dark"}
notice -> 界面偏好已保存，已生效×
SETTINGS SMOKE PASSED
```

补充场景：

- `THINKING=1 node tools/settings-smoke.mjs` → `thinking -> {"level":"high","restarted":true}`：
  设置写入 `ui.thinkingLevel`，agent-host 被停止（日志出现第二次 `[agent-host] stopped`），
  下次打开会话按 high 创建。
- `EMPTY=1 node tools/settings-smoke.mjs` → 空配置（无模型）下只改外观也能保存成功，不再被
  「请填写 Base URL」拦截。

## 已知取舍

- 设置仍按「用户」维度保存，暂无按项目覆盖（Vibelution 的 per-project profile 未搬）。
- 未搬网络代理、日志等级、语言、宠物、自动更新等与 OpenFuture 架构无关的字段。
- 外观设置只影响渲染层；缩放通过 `webContents.setZoomFactor` 实现，不改变窗口尺寸。
- 思考等级修改会停止 agent-host（等价于重启），正在流式输出的对话会被打断；界面会提示。

## 复现

```bash
pnpm build
node tools/settings-smoke.mjs
THINKING=1 node tools/settings-smoke.mjs
EMPTY=1 node tools/settings-smoke.mjs
```
