# P3.2 会话取证与错笔记纠正验收记录

日期：2026-11-09
基线：P3.1 安全整改（`release/p3.1-security-runnable`）
本轮产物：`release/p3.2-evidence-runnable`

## 1. 范围

按 `docs/P3-独立验收与优化方案.md` 的后续项，补齐：

1. 把当前 Pi 会话导入为 L0 证据（会话取证）。
2. 对 L1 错笔记提交结构化 `fix` 候选，批准后只更新目标笔记并刷新当前 L3 投影。
3. 撤销纠正所用证据后，未批准的旧 `fix` 候选必须拒绝，笔记不得被改写。

本轮不包含安装包，不覆盖已有候选目录。

## 2. 实现

### 2.1 会话取证

- 协议：`ImportSessionEvidenceInput`、`OpenFutureApi.memoryImportSessionEvidence`、`IpcChannels.memoryImportSessionEvidence`。
- 主进程从当前会话的 Pi JSONL 中读取 `type=message` 的 user/assistant 文本，生成 `# 会话取证 <id>` Markdown，经 `memoryHost.importSource` 以 `origin=session:<id>`、`kind=session` 写入证据与 FTS。
- 文件读取上限 2 MB；只读取会话目录内的 jsonl；不把原始 JSONL 写入工作区。

### 2.2 错笔记纠正

- 协议：`MemoryProposal.kind`、`MemoryProposal.targetNoteId`、`CorrectNoteInput`、`OpenFutureApi.memoryCorrectNote`。
- `memory-host` 新增 `proposals.kind/target_note_id` 列（旧数据默认 `note`）。
- `correctNote`：目标笔记必须 active；`evidenceIds` 1–20 条且全部属于本工作区、来源与证据均 active；写入 `pending` 的 `fix` 候选，不改动原笔记。
- `decideProposal`：
  - `fix` + approve：再次校验目标笔记与全部证据仍 active；更新 note.body、revision+1、updated_at；写 `note_versions`；重写 FTS；`bumpRevision`；刷新当前 active L3 投影（`refreshActiveProjection`）并重写 `MEMORY.md`；最后标记 approved。
  - 证据已撤销时返回 `VALIDATION`，不更新笔记。
- 渲染层：笔记卡片增加「纠正」，输入纠正正文和证据 ID；候选页显示「纠正现有笔记 …」，批准按钮为「批准纠正」。

## 5. 状态、限制与未完成

- 新会话 system 注入已由 3.5 的 mock 复验确认：`systemHasMemory:true`，含纠正正文、不含旧正文（`.scratch/p4b-system-injection.json`）。
- `refreshActiveProjection` 对当前 active version 原地刷新（修正 L1 后立即生效）；这会改变该版本的历史 `l3_content`，审计请以 `note_versions` 与 `MEMORY.md` 镜像为准。
- 纠正候选的 `expectedRevision` 仅使用目标笔记当前 revision 校验，不要求调用方传入旧 revision；若需要并发保护，后续可增加。
- P3.2 产物本身未含 QMD/Wiki 运行时；该能力已在 P3.3（`release/p3.3-qmd-wiki-runnable`）接入，P3.2 产物仍以 SQLite FTS5 + 确定性 Wiki 草稿为准。
- 打包未签名、`asar:false`；未生成安装包。

## 6. 建议的独立复验

1. 启动 `release/p3.2-evidence-runnable/OpenFuture.exe --remote-debugging-port=<port>`（使用隔离 `OPENFUTURE_USER_DATA`）。
2. 配置本地 mock 端点与假 Key，模式设为 `both`。
3. 导入当前会话为证据；对一条笔记调用 `memoryCorrectNote`，批准候选。
4. 新建会话发消息，检查 mock 收到的 system 消息：应含纠正正文，不含旧正文。
5. 另建一条 fix 候选，先撤销其证据来源，再批准：应返回 `VALIDATION` 且笔记 revision 不变。
