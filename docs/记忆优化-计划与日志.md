## 三种记忆架构（本轮目标）

| 模式 | 检索范围 | 入口 | 现状 |
| --- | --- | --- | --- |
| `rag` | evidence + note + wiki | 设置 → 记忆模式；`memory_search` | 词法检索已打通，精确查询强、语义改写弱 |
| `wiki` | 仅 wiki 页面 | `verify` 发布后的 Curated Wiki | 有检索与详情，缺少质量评测与新鲜度治理 |
| `both` | evidence + note + wiki | 混合 | 仅简单合并，无去重与权重调优 |

`off` 不是目标；三种模式共享 `src/memory-host/index.ts` 的 SQLite/FTS5 与 Dreaming 管线。

## 瓶颈清单（按优先级）

1. **无语义层**：同义改写 R@1 = 0，compare R@1 = 45%；需要 embedding + 混合检索（RRF）。
2. **无 reranker**：候选排序只靠 BM25，长文档与多跳问题弱。
3. **wiki 模式缺少评测**：目前评测只覆盖 evidence；wiki 的覆盖率、新鲜度、冲突率未量化。
4. **both 模式无权重/去重策略**：`allowedKinds` 直接合并，跨模式重复文档会挤占名额。
5. **分块与标题**：段落聚合 ≤1400 字符，标题不参与检索。
6. **答案层未评测**：faithfulness / citation correctness 未纳入回归。
