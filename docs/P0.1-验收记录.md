### A2 密钥与端点绑定

- 首次 `127.0.0.1:8791/v1` + 假 Key 绑定成功
- 同端点末尾斜线、不带 Key 可保留绑定；规范化回 `http://127.0.0.1:8791/v1`
- 改路径 `/v2` 或改端口不带 Key 被拒绝：`更改模型端点时必须重新输入 API Key；原 Key 只对旧端点有效`
- 带新 Key 可绑定新端点；切回旧端点同样要求重录
- `settings.json`、`models.json` 无明文 Key；`models.json` 使用 `runtime-injected-credential` 占位

- 旧 `model-api-key.bin` 场景进入 `needs-rebind`，UI 显示重配引导；带 Key 重存后恢复 `bound`，旧文件删除
- Key 经 `ModelRuntime.setRuntimeApiKey()` 注入 Agent Host；子进程环境变量 `OPENFUTURE_MODEL_API_KEY`/`OPENFUTURE_MODEL_CREDENTIAL` 被删除
